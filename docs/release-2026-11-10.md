# Geo PWA reliability release — 2026-11-10

## Delivered

- Public `/tech`: geographic PWA positioning, hotel/campus/golf-club use cases,
  interactive offline explanation, implementation boundaries, source/API links.
- Replaced the park scenario with a golf club. Added `/demo/golf` with synthetic
  location, live recalculated distance (2.3 km → 943 m), and a 27-second recording
  with captions at `/tech#demo`. The interactive demo is available offline.
- Versioned complete offline shell, separately bundled map worker, real offline
  deep-link restart, account-safe HTTP caching and verified map downloads.
- Atomic local edits/outbox writes; ownership filtering; startup/online recovery;
  cross-tab write serialization; stable local IDs and snapshot reconciliation.
- Atomic PostgreSQL mutation/receipt, concurrency lock and request fingerprint;
  immutable replay and explicit permanent conflict state; additive migration 005.
- Request limits, finite coordinates and bounding boxes, trusted proxy boundary,
  real database readiness, graceful shutdown and bounded SMTP delivery.
- Updated React/Vite/MapLibre and Go dependencies; removed stale generated config
  files; local checks cover PostGIS integration, vulnerability scans and browser scenarios.
- GitHub is a source archive only: Actions and automatic dependency PRs are disabled
  at the owner's request; no workflow files are shipped.
- Architecture and deployment documentation describe actual guarantees and limits.

## Validation

Final golf follow-up: 31 frontend tests, 20 browser tests and production build
pass. Server rebuild and live health, demo and video range delivery checks pass.
See the iteration log for exact results.
Unit tests cover domain/UI behavior; real PostGIS tests cover replay, parallel
submission and rollback; browser tests cover four Chromium mobile profiles in
light/dark modes and actual offline reload with a downloaded PMTiles package.
Physical iOS/Safari GPS and compass accuracy, real email delivery and indoor
positioning are not validated by Chromium emulation. No claim of universal spam,
security or hardware-proof behavior is made.

## Compatibility

Preserves existing places/accounts and external runtime configuration. Migration
005 is additive. The old timestamp changes endpoint remains available but is
bounded, deprecated and explicitly requires bootstrap; it is not a reliable
replication cursor. The current PWA uses outbox + bootstrap.

from the visitor. The same component powers golf, hotel, campus and city examples,

accessible from the first screen. All 33 unit and 28 browser tests pass, including

simulated; the examples do not claim indoor navigation or real GPS validation.

and `wifiyka.service` restart succeeded; the published offline-shell version is
`2437295280cffa1c`. An existing browser installation updated after a reload.
